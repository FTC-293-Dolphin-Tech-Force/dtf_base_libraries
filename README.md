# dtf_base_libraries

Hello! FTC Team 293 is currently developing a library for robot control during both autonomous and teleop, but especially autonomous. It runs using a behavior manager, which allows it to perform complex tasks and easily run tracking pipelines at the same time as movement code. Currently, the only available features are path planning for mecanum robots, but the code is set up so that it should be possible to interchange any hardware component. The documentation is sparse right now since development is the top priority, but we'd love it if any experienced programmers could take a look and give any feedback.
